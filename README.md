# Flow for Mac

Dock の前と壁紙に、ドット絵風の景色を描くアプリです。紹介・使い方・景色の作り方は **[Flow のページ](https://github.com/kodair918-del/flow-releases)** にあります（Windows 版と同じアプリです）。

## インストール（ターミナルに貼って実行）

```bash
curl -fsSL https://raw.githubusercontent.com/kodair918-del/flow-mac-releases/main/install.sh | bash
```

ダウンロード、`~/Applications` への配置、警告の解除、起動まで自動です。macOS 13 以降。

## アップデート

1日に1回、新しい版を探して自動で入れ替えます（メニューで切れます）。

## 景色を足す

メニューの「追加パック」から、サンプルを入れたり、作り方のガイドを開いたりできます。
AI に作ってもらうプロンプトもあります（<https://github.com/kodair918-del/flow-releases/blob/main/docs/PROMPT-FOR-AI.md>）。

このリポジトリには、できあがったアプリ（`dist` ブランチ）とインストール用スクリプトだけを置いています。
