# Flow for Mac

Flow は、Dock の前に景色（星・雪・川・森など）を描くアプリです。

## インストール（1行）

ターミナルに貼って実行します。ダウンロード、`~/Applications` への配置、警告の解除、起動まで自動です。

```bash
curl -fsSL https://raw.githubusercontent.com/kodair918-del/flow-mac-releases/main/install.sh | bash
```

## アップデート

何もしなくても、1日に1回、新しい版を探して自動で入れ替えます。
メニューバーの波のアイコンの「更新」の行から、いますぐ確認・更新もできます（自動更新は同じメニューで切れます）。

このリポジトリには、できあがったアプリ（`dist` ブランチ）とインストール用スクリプトだけを置いています。
